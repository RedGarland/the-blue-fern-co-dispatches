Core rule:
NO FACT WITHOUT A TRACEABLE SOURCE.

Every claim, summary, signal, count, event, and interpretation must be traceable back to a source record, source URL, source title, source date, or local archived source metadata. If a fact cannot be traced, it should not appear in public or paid output.

Project framing:
This project is a byproduct of the existing Gaza Dispatch and Cascadia work, but it should become its own standalone dispatch system.

It should support:
1. Free public summary dispatches for lay readers.
2. More detailed source-backed datasets and artifacts that may later be monetized.
3. Gaza-related dispatches remain fully free.
4. Cascadia and future non-Gaza dispatches may eventually include paid/detail tiers.

Important:
Anything monetized later must have meticulous records:
- source URLs
- source titles
- publisher/outlet
- retrieval date/time
- publication date/time when available
- local archive path when available
- story/category assignment
- curation/scoring reason
- inclusion/exclusion decision where practical
- edition/date generated
- whether used in free summary, paid detail, or both

Use the Cascadia scoring/curation philosophy from the existing agent file, but do NOT reuse Cascadia pipeline output folders or make this depend on the existing FDA/Cascadia project structure. This is a brand-new dispatches system with its own files, modules, outputs, backups, and records.

Relevant curation principles from the Cascadia agent:
- No fact without a source.
- No signal without relevance.
- Remove sports, entertainment, trivia, filler, and unsupported content.
- Prioritize system-relevant signals such as infrastructure, public safety, healthcare, economic disruption, policy/system impacts, humanitarian impact, civic services, supply chains, and institutional stress.
- Public output must be human-readable and must not expose internal pipeline/debug language.
- Public/free and paid/detail data tiers must remain strictly separated.
