# Cascadia Mapping Philosophy

## 1. Product definition
The Cascadia Pressure Map is a calm, source-backed regional systems weather map that shows where public pressures are accumulating across Washington, Oregon, and Idaho. It is designed for civic situational awareness, not alarm, and it prioritizes traceable reporting, clear place context, and consistent week-over-week visibility.

## 2. What counts as pressure
Tier 1 pressure categories are:
- Housing / homelessness / utility stress
- Food insecurity / food support demand
- Health care access
- Transportation / ferry / road / transit disruption
- Public safety and emergency service capacity
- Wildfire / drought / flood / recovery
- Utility / water / power stress
- Local government or school service reduction
- Layoffs / economic insecurity

## 3. Secondary indicators
Secondary indicators are visible only when regionally meaningful:
- school budget cuts
- Medicaid/benefit delivery disruption
- transit funding strain
- clinic negotiations
- agricultural stress
- insurance access/cost strain
- disaster recovery administration

## 4. What is excluded
Excluded from map eligibility:
- generic politics
- opinion/editorials
- crime-only stories without systems implications
- newsroom updates
- celebrity/local fluff
- national stories without Cascadia impact
- static landing pages
- old alert/reference pages without current relevance

## 5. Geographic philosophy
Preferred mapping hierarchy:
- facility/address
- neighborhood
- city
- county
- corridor/service area
- region
- statewide

Rules:
- prefer specific places
- avoid state centroids as default map pins
- regional/statewide reports should live in a separate layer
- never invent precision
- always label uncertainty plainly

## 6. Source philosophy
Rules:
- no fact without source
- public/local/regional sources preferred
- source URL required
- publisher required
- date required
- stale pages excluded from current map
- official sources are useful but not automatically current

## 7. Visual philosophy
The map should feel like:
- NOAA
- National Weather Service
- PBS
- civic resource map
- regional weather map

The map should not feel like:
- Tableau
- breaking-news alert board
- crisis dashboard
- corporate KPI dashboard

## 8. User experience philosophy
Reader should be able to answer:
- What is happening?
- Where?
- Why does it matter?
- Who reported it?
- Is this local, regional, or statewide?

## 9. Time philosophy
Weekly Sunday-Saturday cadence.

Future direction:
- time slider
- week-by-week playback
- accumulation/overlap view

## 10. Overlap philosophy
Pressure becomes more meaningful when:
- multiple categories overlap
- reports repeat over time
- neighboring places show related strain
- local and regional signals reinforce each other

## 11. Honest incompleteness
The map should clearly say when:
- no local reports qualified
- source coverage is thin
- a marker is regional/statewide
- location precision is approximate

## 12. Implementation rules
Map implementation rules:
- no generic "Regional systems pressure"
- no stale reference pages
- no state-only local markers
- pressure category must resolve
- date must be current
- source must be traceable
- precision label must match coordinate basis
