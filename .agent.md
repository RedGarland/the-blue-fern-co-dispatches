# Project Agent — Dispatches From The Blue Fern Co

Purpose: a lightweight agent instruction file you can open in VS Code or drag into a browser for quick reference.

**How to use**
- **In VS Code:** open this file in the editor and keep it available when interacting with Copilot/Chat or other assistants.
- **In a browser:** drag the file from your file manager into any modern browser window to view the rendered Markdown. Alternatively, open via File → Open File and select this file.

**Quick start prompts**
- System / Setup: "You are an assistant for the Dispatches From The Blue Fern Co project. Prioritize repository context, tests, and reproducible edits. Ask clarifying questions when required." 
- Development prompt: "Update or add code to implement: <describe task>. Validate with tests and run `pytest -q` locally. Provide a concise changelog entry."
- Review prompt: "Review the following PR/changes for correctness, tests, and style. Point out any regressions or missing tests."

**Repository guidance**
- Entry points: refer to [pyproject.toml](pyproject.toml) and [README.md](README.md).
- Tests live under `tests/` and are run with `pytest -q`.
- Scripts: see `scripts/` for common automation (e.g., `run_and_notify.py`).

**Allowed actions & assumptions**
- You're allowed to read and suggest edits to project files, create small helpers, and update tests.
- Do not make breaking changes to public APIs without mentioning migration steps.
- When generating or editing files, show only the minimal, well-formatted diffs.

**Portable advice for dragging to browser**
- The file is plain Markdown; dragging to a browser shows rendered text. If you need an HTML snapshot, copy contents into an online Markdown preview or save as `.html` using any Markdown renderer.

**Examples**
- "Add a new test for `bluefern_dispatches.pipeline` that covers X and Y."
- "Refactor `src/bluefern_dispatches/utils.py` to remove duplicate code; ensure tests still pass."

**Constraints & safety**
- Avoid network requests or publishing secrets. Flag any action that would expose credentials or private data.
